JOOUST STORE

This project is a Next.js + PostgreSQL + Prisma app. VS Code Live Server can only serve static files, so you must run the Next.js dev server for the real app.

Run locally (recommended)

Open Shop (localhost:3000) Open Admin (localhost:3000/admin)
  1. Copy .env.example to .env and set DATABASE_URL + JWT_SECRET.
  2. Install dependencies.
  3. Run migrations and seed.
  4. Start the dev server.
npm install
npm run prisma:migrate
npm run db:seed
npm run dev

Deploy live (Vercel)

  1. Push the repo to GitHub.
  2. Import it in Vercel (Framework: Next.js).
  3. Set env vars in Vercel:
    • DATABASE_URL
    • JWT_SECRET
    • NEXT_PUBLIC_APP_URL
  4. Run production migrations against hosted DB:
npm run prisma:migrate:deploy

Notes

  • Live Server can open this index.html file, but it cannot run the Next.js backend or the database.
  • If the links above show an error, start the app by running npm run dev.
